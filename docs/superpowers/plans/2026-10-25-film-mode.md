# Film mode: implementation plan

Spec: `docs/superpowers/specs/2026-10-25-film-mode-design.md`. Execution: native (inline, TDD), then one fresh reviewer.
Each task: failing test → implement → `npm test` + `npm run typecheck` → commit.

1. **Data**: migration #4, schema, `Note` fields, `NoteStore.create(audio)` takes `kind/windowTitle/show`; `setStarred(ids, on)`, `setShow(id, show|null)`. Settings `filmMode`, `rewindSeconds`, `autoPause` (+ zod). Boot forces `filmMode: false`.
2. **Pure helpers**: `shared/show.ts`, `shared/search.ts`, `shared/ring-buffer.ts` with unit tests.
3. **win32 adapter**: `main/win32.ts` (koffi) + packaging (`NATIVE_MODULES` + `@koromix/koffi-win32-x64`, vite externals).
4. **Controller**: `getContext`, `onCaptureStart/End`, `rewind()` / `'rewinding'`, `kind` on audio.
5. **AutoPause** policy + probe IPC.
6. **Hotkey**: rewind combo in `HotkeyService` (`onRewind`), media-key events ignored.
7. **Overlay**: `ring-worklet.js`, `useFilmBuffer` (mode, save, probe), `busy` overlay state, idle film dot, rewind encode via mediabunny.
8. **Main wiring**: film mode side effects, tray checkbox, rewind handler, auto-pause, context provider (test override), new dashboard IPC (`notes:star`, `notes:set-show`).
9. **Dashboard**: search bar + filters, Starred view + count, star toggle, show chip + "Edit show", rewind badge, Settings rows.
10. **E2E**: rewind, context, search/star, film dot. Update `CLAUDE.md`.
11. Final review (fresh opus reviewer) → fix pass.
