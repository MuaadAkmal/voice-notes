# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

**Voice Notes**: a Windows Electron app. A global hotkey (default Alt+Win) shows a floating pill that records a voice note to a local `.webm` file indexed in SQLite. A dashboard organises notes into nested folders (Inbox = unfiled), and plays, renames, moves (drag & drop, multi-select), stars, searches and deletes them, alongside markdown text notes (pages). **Home** (the default view) shows widgets the user picks: quick-add boxes that append `- entry` under today's `## D Mon YYYY` heading of a chosen page, and pinned pages rendered read-only. **Film mode** (tray/Settings toggle, off at every launch) keeps the last 60 s of system audio in memory; Alt+Win+Shift saves the last N s as a `rewind` note. Mic notes pause playing media (play/pause key) and resume after. Every note stores the foreground window title and a cleaned `show` label. **Transcription** (on demand, per note or selection) sends a note to the user's own OpenAI-compatible Whisper server (e.g. vLLM), or to the **Built-in** provider: a pinned whisper.cpp CPU build plus a model the user picks, downloaded on demand from upstream (GitHub release, Hugging Face; SHA-256 checked) and run as `whisper-server.exe` on 127.0.0.1 behind the same client, unloaded after 5 min idle. Both are set up on the Transcription page; the transcript is stored on the note, editable and searchable. Cloud providers are listed as Coming soon. **Review later**: dragging a link or text from a browser onto the visible pill (idle or "Saved", never while recording) appends a `- [ ] …` line under today's heading of the built-in Review later page (can't be deleted; its Home card is `locked` and always first). **Dictation**: Ctrl+Win (hold, or double-tap for hands-free; its own `HotkeyGesture`) records the mic, sends the clip to the same Whisper server and pastes the text at the cursor of the focused app (clipboard + Ctrl+V once the modifiers are up, previous clipboard restored 500 ms later). Texts (never audio) are kept 24 h in the Dictation panel. Dictation and voice notes exclude each other. Specs: `docs/superpowers/specs/`; plans: `docs/superpowers/plans/`.

## Commands

- `npm start`: run in dev (Electron Forge + Vite, HMR for renderers)
- `npm test`: Vitest unit tests. Runs **under Electron as Node** (`ELECTRON_RUN_AS_NODE=1`) because `better-sqlite3`/`uiohook-napi` are rebuilt for Electron's ABI by `postinstall`. Never run vitest with plain `node`/`npx vitest`. Filter: `npm test -- gesture`.
- `npm run typecheck`: `tsc --noEmit`
- `npm run package` / `npm run make`: packaged app / Squirrel installer in `out/`
- `npm run test:e2e`: runs `package` (emits the production Vite build to `.vite/`), then Playwright `_electron` tests in `tests/e2e/` (shared launcher `tests/e2e/launch.ts`; screenshots to `.superpowers/shots/`). Home is the default view, so specs click Inbox first (`getByRole('button', { name: /^Inbox/ })`). Stop any running `npm start` first: its watcher rewrites `.vite/` with dev-server URLs. Close the packaged app before packaging (it locks `out/`). The launcher sets `colorScheme: null` so Playwright doesn't force light mode. They launch `electron .` with the dev binary, not the packaged exe, because packaged fuses disable the Node inspector Playwright needs.
- Packaging: Vite bundles everything except `better-sqlite3`/`uiohook-napi`/`koffi`; `forge.config.mts` `packageAfterCopy` copies them (plus `node-gyp-build`, and `koffi` whole with its `@koromix/koffi-win32-x64` binary) into the package. Add any new native module there and to `vite.main.config.mts` externals. (`fflate` is pure JS and bundled.)

## Architecture

- `src/main/`: Electron main. Pure, unit-tested core (`hotkey/gesture.ts`, `recorder/controller.ts` incl. `rewind()` and capture start/end hooks, `media/auto-pause.ts`, `drop/drag-watch.ts` (global mouse held over the overlay → solid, so OS drops land; the renderer's hover comes too late during a drag), `later.ts` (`ensureLaterPage` at boot, `saveDrop`), `dictation/controller.ts` (listening → transcribing → save → paste; `blocked()`/`dismissFlash()` keep it and `RecorderController` apart), `dictation/paste.ts` (`pasteText`: snapshot, write, wait for modifiers, Ctrl+V, restore), `store/note-store.ts`, `store/folder-store.ts`, `store/page-store.ts`, `settings.ts`) plus thin Electron adapters (`hotkey/service.ts` uiohook with the rewind combo, `win32.ts` koffi: foreground window, play/pause key, `sendCtrlV`, `modifiersHeld`, `dictation/clipboard.ts` (Electron 45's async clipboard: snapshots every format via `read()`), `windows.ts`, `overlay-mouse.ts` (one click-through flag from hover + drag), `ipc.ts`, `protocol.ts` (`note://<id>` audio, `vn-image://<uuid>.<ext>` page images; renderers never see paths), `tray.ts`). `local-whisper/`: `catalog.ts` (pinned engine tag `b5454`, model revision, sizes, hashes; `recommendedModel`, `threadsFor`), `installer.ts` (download to `.part` with progress, address fallback, hash check, `fflate` unzip keeping `whisper-server.exe`/`whisper.dll`/`ggml*.dll`, cancel, cleanup), `server.ts` (`EngineServer`: OS-picked free port, ready only when `GET /` says `Whisper.cpp Server`, shared start, 5 min idle kill, model switch restart, `server.pid` orphan kill at boot), `index.ts` (`LocalWhisper` facade + spawn/tasklist adapters). `transcription/endpoint.ts` (`resolveEndpoint`: server or built-in engine, with `release()`; used by the service and dictation, which prewarms the engine when listening starts and waits up to 120 s on built-in). `transcription/`: `openai-client.ts` (`POST {baseUrl}/audio/transcriptions` with injected fetch; `verbose_json`, one retry as `json` on 400/422), `queue.ts` (FIFO, one job at a time, in-memory `StatusMap`), `secrets.ts` (API key via `safeStorage` in `secrets.json`), `wav-bridge.ts` (asks the dashboard to convert a clip to WAV; main has no audio decoder), `service.ts` (wires them; settings and key are read when a job starts). `index.ts` wires them.
- `src/preload/`: one sandboxed preload per renderer (`overlay.ts`, `dashboard.ts`), built to `.vite/build/<name>.cjs`.
- `src/renderer/overlay/`: the floating pill; owns capture (`useRecorder.ts`: mic via getUserMedia, system audio via getDisplayMedia answered by main's `setDisplayMediaRequestHandler` with `audio: 'loopback'`, or a WebAudio mix for "both"). Hand-built on purpose: no shadcn/Radix/lucide in the overlay bundle. `Pill.tsx`: canvas loudness waveform (`src/shared/audio-level.ts`), "No sound" after 3 s of silence, hands-free lock + discard ×, "Saved ✓ · Add title" (main makes the overlay focusable only while the title input is open). `useFilmBuffer.ts`: film mode (loopback → `ring-worklet.js` AudioWorklet → `RingBuffer`; rewind encodes with mediabunny/WebCodecs Opus in `encode.ts`) and the auto-pause `probe` (waits for the note's mic via `capture.ts` `clipOpened` so it never delays it). `usePomodoro.ts` + `Pomodoro.tsx`: hovering the idle bar raises a 25/5 pomodoro chip above it (logic pure in `src/shared/pomodoro.ts`); a running timer fills the bar, and a phase change glows and chimes (silent while recording). `useDropLater.ts`: window-level drag/drop listeners → `later:drop`; `DropPill` shows "Drop to save for later" / "Saved for later ✓". Dictation clips come through `useRecorder` too (`recorder:start` with `dictation`): converted with `renderer/common/to-wav.ts` and sent on `dictation:audio`; `ping.ts` plays the start sound; the recording pill shows "Dictating". `useDrag.ts`: drag past 4 px moves the window (`overlay:drag`), position saved as `pillPosition` and resolved by `src/main/overlay-position.ts`.
- `src/renderer/dashboard/`: `App.tsx` owns the `View` (`home | inbox | all | starred | folder | page | settings`, Home first, where Back from a page goes, and the search filter so it survives opening a page) and loads notes, pages + folders; `Sidebar.tsx` (folder tree, inline create/rename, drop targets), `NotesPage.tsx` (merged list of voice notes and text pages via `src/shared/items.ts`: `NoteRow`/`PageRow`, selection, drag source, `New text note`), `PageView.tsx` (text note: title + `editor/MarkdownEditor.tsx`, a CodeMirror 6 live-preview markdown editor (`preview-spans.ts` pure + unit-tested: which spans render vs stay raw; `live-preview.ts` decorations; `widgets.ts` checkbox/image/rule/table widgets; `theme.ts`; `insert-anchor.ts` positions that follow edits while an image saves); body autosaved through `DebouncedSaver` 500 ms, flushed on blur, navigation and `beforeunload`; Pin to Home toggle), `HomePage.tsx` (4-column grid of 120 px rows, 2/1 columns when narrow; each card spans `w`×`h` cells (1–4, defaults quick-add 1×2, page 2×2), resized by its corner handle or the ⋯ Size presets; a card is dragged by its header onto another card to take its place; `AddWidgetDialog.tsx`; `widgets/QuickAddWidget.tsx` input + today's entries; `widgets/PageWidget.tsx` `MarkdownEditor readOnly`: everything renders; its checkboxes go through the main-side per-line `pages:set-task` edit, never `setPageBody`, which could overwrite concurrent quick-add appends), `useHomeWidgets.ts` (the `homeWidgets` setting; edits always start from the latest list; pin/unpin, also used by `PageRow` menu and `PageView`), `dnd.ts` (current drag payload, since dataTransfer is unreadable during dragover), `TranscriptionPage.tsx` (My server | Built-in choice; server URL/model, key, test connection; default language), `LocalWhisperCard.tsx` (model list with Recommended badge, download progress/cancel, delete, Use built-in, Test), `DictationPage.tsx` (last 24 h, search, Copy through main since the dashboard has no clipboard permission, Clear all), `useTranscription.ts` (job status + Transcribe, used by `NotesPage`/`NoteRow`), `../common/to-wav.ts` (decode + resample to 16 kHz mono, shared with the overlay; answers `transcription:need-wav`, registered in `main.tsx`), `Toast.tsx` (Sonner), `ConfirmDialog.tsx` (`useConfirm`). shadcn/ui components live in `src/renderer/dashboard/components/ui/` (`@/` alias → `src/renderer/dashboard/`); add more with `npx shadcn@latest add <name>`, then check imports use `@/lib/utils` (the CLI once rewrote it to an npm package `cn`).
- Theme: settings `theme` → `nativeTheme.themeSource` (main) → `prefers-color-scheme` → `html.dark` (dashboard `main.tsx`); caption buttons recoloured by `applyTitleBarTheme`. Colours are shadcn tokens in `dashboard.css`; use tokens, not raw stone-* classes.
- `src/shared/`: IPC channel names, payload types and zod schemas (`ipc.ts`), plus pure helpers: `format.ts`, `folders.ts` (tree, path, cycle check, range selection), `show.ts` (window title → show label), `search.ts` (accent-insensitive note/page filter), `items.ts` (merged note + page list), `markdown-snippet.ts`, `learn-log.ts` (today's heading, `appendEntry`, `todayEntries`), `home-widgets.ts` (add/remove/rename/move/pin/prune/keepExisting widget lists, max 24), `task-lines.ts` (task-list line parsing/toggle for the per-line checkbox edit), `page-images.ts` (image ext/size limits, `vn-image` refs), `later.ts` (`parseDrop`, `laterEntry`, `acceptsDrops`), `dictation.ts` (TTL, minimum length, `filterDictations`, `sameCombo`), `transcription.ts` (languages, base-URL normalising, provider defaults), `transcription-errors.ts` (failure → user message), `wav.ts` (16-bit PCM WAV encoder), `debounced-saver.ts`, `ring-buffer.ts`, `audio-level.ts`.
- Vite configs are `.mts` (Forge 8). Renderer roots are `src/renderer/<name>`; CSP is injected at build time only (`vite.csp.mts`).

## Data

`%APPDATA%/Voice Notes/`: `recordings/<uuid>.webm`, `images/<uuid>.<ext>` (pasted/dropped page images), `voice-notes.sqlite`, `settings.json`, `logs/`. Folders are database rows only (migration #2); notes carry `source` mic/system/both (migration #3) and `kind` note/rewind, `window_title`, `show`, `starred` (migration #4); notes gain `transcript`, `transcript_lang`, `transcribed_at` (migration #6; `''` = no speech; setting it never bumps `updated_at`); text notes are the `pages` table (migration #5: title, markdown body stored exactly as typed, folder, starred); deleting pages removes images no other page references and prunes their Home widgets; audio files never move. `settings.json` `transcription` (`provider` server/local/null, normalised `baseUrl`, `model`, `localModel`; a `local` provider whose model file is gone falls back to null at boot) and `transcribeLanguage`; built-in files live in `whisper/` (`engine/<tag>/`, `models/`, `server.pid`); the API key lives only in `secrets.json` (`safeStorage`-encrypted, never sent to a renderer). `homeWidgets` lists the Home cards in order (`quick-add` with `label` + `pageId`, or `page`; optional `w`/`h` spans, `locked` for the Review later card, which `removeWidget`/`unpinPage` keep and main re-adds via `ensureLocked`); `laterPageId` names the built-in page; no migration. Dictations are the `dictations` table (migration #7: text, app label, created_at; pruned to 24 h at boot and hourly); settings `dictationHotkey`/`dictationHotkeyLabel` (default Ctrl+Win, must differ from the recording and rewind combos) and `dictationSound`. Override the data dir with env `VOICE_NOTES_USER_DATA` (used by e2e). `VOICE_NOTES_TEST=1` exposes `globalThis.__voiceNotes` in main for Playwright and skips the global keyboard hook (so a person typing during a test run can't interfere). `launch({ userData })` reuses a data dir (relaunch tests); `launch({ fakeAudioFile })` feeds a WAV to the fake mic, e.g. `tests/e2e/fixtures/silence.wav`. Under fake devices the **loopback stream is the fake input too** (`tone.wav` = "media is playing"). Test hooks also expose `rewind()`, `pagesChanged()` (after editing `store.pages` directly), `openedExternal` (URLs the dashboard asked to open in the browser), `transcription` (`idle()` waits for queued jobs; e2e points it at a fake OpenAI-compatible server), `setForeground(fn)` (no real foreground window in tests) and `mediaPresses()` (auto-pause only counts presses under `VOICE_NOTES_TEST=1`), `dictationGesture` (what Ctrl+Win does) and `pasted` (texts a dictation would have pasted; no real paste under test), `localWhisper` (`setTestOverrides({ catalog, spawn: { script } })`: serve fake downloads and run `tests/e2e/fixtures/fake-whisper-server.mjs` instead of the engine).
